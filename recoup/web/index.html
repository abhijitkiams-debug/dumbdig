What to include

Recoup understands common column synonyms. Helpful fields (all optional; missing ones are imputed):

  • account_id / loan_id
  • past_due_amount / overdue, next_installment_amount / emi
  • current_bucket / dpd, days_past_due
  • payment history: last_pay_amount, pay_ratio_6m, num_payments_12m
  • contact history: rpc_rate, promises_kept_6m, refusals_6m, preferred_channel
  • geo for routing: geo_x/longitude, geo_y/latitude, region
  • optional labels to evaluate accuracy: label_actual_payment, label_promise_to_pay
